# Lil Buddy Roadmap

## v0.1 Developer Preview

Goal: prove the core experience.

- Finish MVP polish
- Stabilize settings and themes
- Improve onboarding
- Improve Telegram gateway setup
- Harden safe defaults
- Add reset settings / safe mode
- Add better error reporting
- Prepare signed builds where possible
- Release public developer preview

## v0.2 Community Preview

Goal: make Lil Buddy easier to install and understand.

- Cleaner docs
- Demo video
- Companion/theme polish
- Better expert templates
- Search/planning helper templates
- Safer workspace defaults
- Better cross-platform packaging
- Community issue templates
