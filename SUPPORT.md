# Support

Lil Buddy is currently a Developer Preview.

## Free support

Please use GitHub Issues for:

- reproducible bugs
- installation problems
- feature requests
- docs improvements
- platform-specific reports

## Before opening an issue

Include:

- operating system
- app version/commit
- screenshots or logs
- steps to reproduce
- whether you are using Telegram gateway
- whether a workspace was selected

## Optional paid support later

The maintainer may later offer:

- hosted Telegram gateway
- cloud sync
- official signed builds
- premium companion packs
- priority setup help
- custom expert/template setup
