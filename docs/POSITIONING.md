# Positioning

Lil Buddy is not mainly a coding app.

Suggested framing:

> Lil Buddy is a local-first desktop AI helper for planning, searching, organizing, writing, learning, light coding, and everyday work.

Short options:

- Your local-first desktop AI helper.
- A little desktop companion for thinking, planning, searching, and getting work done.
- A personal AI helper with experts, companions, and optional Telegram access.

Avoid positioning Lil Buddy as:

- another AI code editor
- a Cursor replacement
- a Copilot replacement

Better lane:

- local-first
- personal
- customizable
- companion-driven
- provider-flexible
- useful for everyday work
