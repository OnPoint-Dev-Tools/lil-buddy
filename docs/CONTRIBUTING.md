# Contributing to Lil Buddy

Thank you for considering a contribution.

Lil Buddy is in Developer Preview, so the best contributions are practical and focused.

## Good first contributions

- bug reports with screenshots
- cross-platform testing notes
- documentation improvements
- theme polish
- accessibility improvements
- expert template ideas
- provider integration fixes
- Telegram gateway setup notes

## Before opening a pull request

Please:

1. Open an issue or discussion for larger changes.
2. Keep pull requests focused.
3. Include screenshots for UI changes.
4. Explain the platform you tested on.
5. Avoid committing secrets, tokens, or private paths.

## Code style

- Keep changes simple and readable.
- Prefer local-first behavior.
- Avoid adding backend dependencies to core flows.
- Do not auto-scan large folders unless the user explicitly asks.
- Keep safety and privacy visible.
